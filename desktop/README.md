# Budget Desktop for Windows

Windows-сборка запускает существующий интерфейс Budget в отдельном окне и
хранит рабочую копию данных в `%APPDATA%\\Budget\\repository\\data`.
Код приложения при этом остаётся внутри установленной программы, а именно
данные синхронизируются с GitHub-репозиторием `Budget`.

## Подключение GitHub

1. Запустите `Budget-1.0.0-win-x64.exe`.
2. В боковой панели нажмите **Подключить GitHub**.
3. Укажите HTTPS-адрес созданного репозитория `Budget` и персональный токен
   GitHub с доступом `Contents: Read and write` к этому приватному репозиторию.
4. Нажмите **Синхронизировать GitHub**.

Если созданный репозиторий пока пуст, первый запуск перенесёт в него каталог
`data` с исходными JSON-файлами и создаст ветку `main`. Токен шифруется средствами Windows для текущей учётной записи. Он не
записывается в рабочий JSON, исходный код или Git-историю.

## Правила одновременной работы

Перед началом редактирования выполните синхронизацию. После изменения JSON
приложение автоматически создаёт коммит только для каталога `data` и отправляет
его в GitHub. Если два пользователя изменили один и тот же файл до обмена,
приложение останавливает отправку и сообщает о конфликте — данные не
перезаписываются молча.
