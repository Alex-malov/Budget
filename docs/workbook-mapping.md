# Соответствие экранов исходным книгам

Структура навигации приложения полностью повторяет порядок вкладок книги
`Бюджетирование (новый).xlsx`. Значения для наполнения взяты из
`Актуальная версия — моделирование 09.06.26.xlsx` и сохраняются в автономном
снимке `data/model-snapshot.json`.

| Экран приложения | Структурная вкладка | Данные исходной модели |
| --- | --- | --- |
| Pipline финансовый | Pipline финансовый | `Свод`, `поступления` |
| Доходы | Доходы | `поступления` |
| Проектные Расходы (себест) | Проектные Расходы (себест) | `Свод` |
| Суммы и часы подряд | Суммы и часы подряд | `План`, раздел «Субподряд» |
| Суммы и часы штат | Суммы и часы штат | `рес_план` |
| Команда | Команда | `Штат` |
| НСИ | НСИ | `НСИ` |

## Принципы представления

- В интерфейс не перенесены демонстрационные записи предыдущей версии.
- Первичные числовые значения являются выгрузкой исходной модели на 09.06.2026.
- «Операционная разница без НДС» рассчитывается в приложении как
  `(объём работ − НДС по доходам) − (себестоимость − НДС в себестоимости)`.
- В строках подрядчиков расчётные часы показываются только при наличии ставки:
  `затраты / ставка`.
- Вкладка «Суммы и часы подряд» показывает одну запись на месяц. Локальные
  добавления и изменения сохраняются в `data/subcontract-overrides.json`; этот
  файл накладывается на снимок и не изменяет Excel-книгу.

## Обновление снимка

Чтобы получить новый снимок после обновления исходной модели, запустите
`scripts/extract_model_snapshot.py` из папки, содержащей две Excel-книги, и
укажите целевой файл `data/model-snapshot.json`.
