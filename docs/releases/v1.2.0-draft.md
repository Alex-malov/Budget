# Budget 1.2.0 — финансовая детализация и проектная сводка

## Назначение релиза

Релиз переводит экран «Прочий подряд» на компактное представление «План / Факт» и заменяет статическую страницу «Проектные Расходы (себест)» расчётной финансовой сводкой по данным приложения.

## Расчёты

- Прочий подряд: `Стоимость = Сумма + НДС`, `НДС = Сумма × месячная ставка НДС`.
- Ресурсы: `Себестоимость = Ставка × часы`, `Привлечение = Привлечение × часы`.
- Подряд: `НДС = (Себестоимость + Привлечение) × месячная ставка НДС поставщика`.
- Штат: НДС не применяется.
- Отклонение: `Факт − План`; процент не рассчитывается при нулевом плане.
