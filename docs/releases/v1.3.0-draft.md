# Budget 1.3.0 · кандидат на выпуск

## Включённые задачи

- BUD-12 — финансовый контур доходов, оплат и план-факта.
- BUD-13 — дизайн-приёмка финансового контура.

## Изменения

- Добавлены независимые регистры поступлений, оплат подрядчикам и финансовых ставок.
- Добавлены экраны «Финансовый план‑факт» и «Оплаты подрядчикам».
- Реализованы сценарии план/факт, расчёт НДС по зафиксированной ставке и контроль распределения оплат.
- KPI содержат план, факт, отклонение, формулу и источник данных.
- Обновлена навигация и стили адаптивных финансовых компонентов.
