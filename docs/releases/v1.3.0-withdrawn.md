# Budget 1.3.0 — снята с использования

Дата: 25.08.2026  
Статус: **откачена до 1.2.0**.

## Причина

Пользователь сообщил о критических логических дефектах в версии 1.3.0. Детализация конкретных сценариев в обращении не предоставлена, поэтому причины не подменяются предположениями. Версия запрещена к повторному выпуску до отдельного анализа дефектов и приёмки.

## Уроки для следующих релизов

1. Включать в сборку только изменения, прямо прослеживаемые к утверждённой задаче.
2. Не заменять действующие расчёты или навигацию без регрессионного сравнения с предыдущей стабильной версией.
3. Не считать финансовые показатели и НДС без проверочного набора ручных контрольных расчётов и сценариев «план / факт / частичная оплата / аванс».
4. Не выпускать сборку без ручной UI-приёмки и подтверждения заказчика, даже если серверные тесты проходят.
5. Для каждой обнаруженной ошибки дополнять этот документ: сценарий воспроизведения, ожидаемый и фактический результат, первопричина, тест против регрессии и версия исправления.

## Состояние отката

- исходный код возвращён к коммиту `2b386de` — версия 1.2.0;
- стабильный запуск: `release/Budget-1.2.0-win-x64/Budget.exe`;
- каталоги 1.3.0 сохранены отдельно как артефакты разбора и не являются текущей версией.
