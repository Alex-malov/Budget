Артефакт размещён отдельно от действующей 1.2.0 в `release/Budget-1.4.0-win-x64/Budget.exe`.

- SHA-256 `Budget.exe`: `8D205E25B40DA3ADA4A08C92F32BFBD8E8D38EDB4BFE443DEEA77FC9DE685BAC`;
- компонент синхронизации GitHub проверен в распакованном runtime;

Откат: закрыть 1.4.0 и запустить сохранённый `release/Budget-1.2.0-win-x64/Budget.exe`. Публикация Git-тега, GitHub Release или замена рабочего экземпляра допускаются только после согласования владельца продукта.
