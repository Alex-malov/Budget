# Реестр релизов Budget

Каждый релиз фиксируется отдельным Markdown-файлом в этом каталоге и содержит:

- версию, дату и Git commit SHA;
- список задач и ссылок на GitHub Project;
- результаты локальных проверок;
- контрольную сумму артефакта Windows;
- подтверждения сборки и деплоя, а также сценарий отката.

Публикация тега, GitHub Release и развёртывание выполняются только после отдельного согласования владельцем продукта.
