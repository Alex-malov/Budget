# Внутренняя дизайн-приёмка BUD-05—BUD-11

Дата проверки: 13.08.2026. Объект: локальная версия Budget 1.2.0.

| Критерий | Результат | Доказательство |
| --- | --- | --- |
| BUD-05: компактность финансовой ячейки | Пройдено | В ячейке последовательно показаны стоимость, сумма и НДС; план и факт имеют разные нейтральные тона. |
| BUD-05: отсутствие данных отличается от нуля | Пройдено | Для периода без введённого значения выводится `—`; нулевое введённое значение остаётся `0 ₽`. |
| BUD-06: навигация периода | Пройдено | Годы свёрнуты, раскрытие одного года закрывает другой; месяцы подписаны сокращённо, полное имя доступно через `abbr` и подсказку. |
| BUD-06: режимы представления | Пройдено | «Компактно» выбран по умолчанию; «Детально» раскрывает отдельные метрики стоимости, суммы и НДС без изменения данных. |
| BUD-07: базовая доступность | Пройдено | Переключатели — нативные кнопки с `aria-pressed`; редактируемые ячейки получают фокус и открываются по Enter; доступен фиксированный горизонтальный скролл. |
| BUD-08: сравнительный информер | Пройдено | Один блок показывает план, факт и отклонение для стоимости, суммы без НДС и НДС; статусы перерасхода, экономии и отсутствия плана обрабатываются отдельно. |
| BUD-09: адаптивность информера | Пройдено | На узком экране информер перестраивается в одну колонку, таблица имеет собственную горизонтальную прокрутку. |
| BUD-10: источник расчёта | Пройдено | Сводка собирается из НСИ, «Команды», «Сумм и часов штат/подряд» и «Прочего подряда», без статической строки листа «Свод». |
| BUD-10: фильтры и расшифровка | Пройдено | Реализованы глобальные проект/год/период, локальные источник/поиск/только отклонения; «Подробнее» открывает помесячную расшифровку. |
| BUD-11: визуальные состояния | Пройдено | Перерасход выделяется красным, экономия — зелёным; таблицы сортируемы, заголовки имеют пояснения; drawer закрывается кнопкой и Escape. |

Проверка не подменяет финальное продуктовое согласование. При замечаниях владельца продукта BUD-07, BUD-09 или BUD-11 могут быть повторно открыты отдельной задачей.
