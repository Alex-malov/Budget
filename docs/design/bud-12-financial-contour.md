# BUD-12 · Финансовый контур: доходы, оплаты и план-факт

## Назначение

Контур сопоставляет план и факт поступлений, начислений расходов и оплат, не смешивая начисление с денежным потоком. Он реализован как три самостоятельных регистра и аналитический экран.

| Контур | Операция | Основные атрибуты | Источник аналитики |
|---|---|---|---|
| Доходы | Событие поступления | Проект, план/факт, месяц, сумма с НДС, ставка НДС, НДС, комментарий | Регистр `income-events.json` |
| Оплаты | Событие оплаты подрядчику | Проект, план/факт, источник, подрядчик, месяц оплаты, сумма с НДС, НДС, документ, распределения | Регистр `contractor-payments.json` |
| НСИ | Финансовая ставка | Тип, проект (при необходимости), год, ставка | Регистр `financial-rates.json` |

## Контроли ввода

- Код проекта обязателен для финансовой операции, уникален без учёта регистра и отображается как `КОД — Наименование`.
- Коды имеют формат `A–Z`, `0–9`, `-`, `_`, длиной 2–32 символа. После появления финансовых операций код нельзя изменить.
- НДС фиксируется в событии и допускает только 0%, 5%, 7%, 10%, 22%.
- НДС события: `сумма с НДС × ставка / (100 + ставка)`; сумма без НДС хранится как производное значение.
- Сумма распределений оплаты не может быть больше оплаты. Нераспределённая часть остаётся допустимым авансом.
- Архивные проекты и контрагенты недоступны для выбора.

## Расчётные показатели

| Показатель | Формула |
|---|---|
| Доход с НДС | Сумма событий поступления выбранного сценария |
| Расходы с НДС | Прочий подряд + подрядные ресурсы + стоимость штатных ресурсов; «Привлечение» штатных ресурсов исключается |
| Валовая прибыль | Доход с НДС − расходы с НДС |
| Итого НДС | НДС поступлений − НДС расходов |
| Прибыль до налога | Валовая прибыль − итоговый НДС |
| Налог на прибыль | `max(0; прибыль до налога) × ставка` |
| Чистая прибыль | Прибыль до налога − налог на прибыль |
| Инвестиции | `(доход с НДС − прочий подряд с НДС) × ставка инвестиций` |
| Дирекция | `(доход с НДС − прочий подряд − инвестиции) × проектная ставка` |
| Распределение ЛТ | Привлечение штатных ресурсов; информер, не расход |
| Овердрафт | `max(0; оплаты − поступления) × ставка` |
| Остаток ДКС | Чистая прибыль − инвестиции − дирекция − ЛТ − овердрафт |

Если обязательная ставка для выбранного года или проекта не задана, зависимый показатель выводится как «Не рассчитано»; ноль не подставляется.

## UI и трассировка 3Р

- №3 — НСИ: проектные коды и финансовые ставки.
- №11 — первичный учёт: формы «Доходы» и «Оплаты подрядчикам».
- №15 — вычисление: финансовый план-факт и формулы показателей.
- №16 — аналитический реестр: сводка план/факт, KPI, расшифровка формулы по клику.

Глобальные фильтры «Проект» и «Год» применяются ко всем трём экранам. Оплата отображается как денежный поток и не увеличивает расходы повторно.
