# Бюджетирование

Локальное веб-приложение для просмотра финансового и ресурсного планирования.

Навигация повторяет вкладки книги `Бюджетирование (новый).xlsx`; исходные
значения выгружены из `Актуальная версия — моделирование 09.06.26.xlsx` в
`data/model-snapshot.json`.

## Запуск

Требуется Node.js 22 или новее.

```powershell
node server.js
```

После запуска откройте `http://localhost:4174`.

## Десктопная версия Windows

Исходный код и сборка размещаются в `C:\Users\МАЮ\YandexDisk\Временная\Бюджеты\ПО\Budget`.
Команда `npm run build:win` создаёт переносимый файл `Budget-1.0.0-win-x64.exe`.
В десктопном приложении локальная рабочая копия JSON находится в профиле
Windows, а изменения синхронизируются с GitHub. Подробности подключения — в
[`desktop/README.md`](desktop/README.md).

## Что отображает приложение

- `Pipline финансовый`: свод по объёму работ, себестоимости, НДС, ФОТ,
  подрядчикам и операционной разнице;
- `Доходы`: поступления по проектам, контрактным периодам и месяцам;
- `Проектные Расходы (себест)`: годовая структура затрат;
- `Суммы и часы подряд`: подрядчики, ставки, затраты и расчётные часы;
- `Суммы и часы штат`: сотрудник × проект × роль, часы и себестоимость;
- `Команда`: численность по ролям и именной состав;
- `НСИ`: роли, контракты, поставщики и ресурсы.

Подробное соответствие вкладок и источников описано в
`docs/workbook-mapping.md`.

В разделе `Суммы и часы подряд` можно фильтровать записи по году, месяцу и
поставщику, а также добавлять и редактировать строки. Эти изменения сохраняются
локально в `data/subcontract-overrides.json` и не перезаписывают исходную книгу.
